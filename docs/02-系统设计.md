# 02 · 系统设计

> 产品代号：**游迹（GameRemainder）** v1.0.0

---

## 1. 技术选型

| 项 | 选择 | 理由 |
| --- | --- | --- |
| 桌面框架 | **Electron**（主进程 CJS，渲染层 ESM） | 跨平台、亚克力支持成熟（`backgroundMaterial`）、生态成熟 |
| 窗口形态 | 无边框 + `alwaysOnTop` + 自绘标题栏 | 满足"悬浮于桌面最上端" |
| 亚克力 | Win11：`backgroundMaterial:'acrylic'`；Win10 回退：`transparent:true` + CSS `backdrop-filter` | 系统级亚克力最正宗；回退方案保持观感一致 |
| 持久化 | 主进程写 `userData/data.json`，临时文件 + 原子替换 | 比 localStorage 可靠、可备份、可导出 |
| 渲染层 | 原生 HTML/CSS/ES Modules，无框架 | 轻量、常驻内存占用小、零构建 |
| 图标 | 纯 Node（zlib 手写 PNG → ICO 容器） | 零依赖生成应用图标 |
| 验证 | Node 单测（模型）+ Electron 冒烟自检 + `capturePage` 截图 | 三层验证 |

## 2. 总体架构

```
┌─────────────────────────────────────────────┐
│  Electron 主进程 (main.cjs)                  │
│  · BrowserWindow 悬浮/亚克力/置顶            │
│  · 系统托盘 / 开机自启 / 窗口控制            │
│  · 数据文件读写（原子替换）+ 导入导出        │
│  · 截图模式 / 冒烟模式                       │
├──────────────┬──────────────────────────────┤
│  preload.cjs │  contextBridge 暴露安全 API   │
├──────────────┴──────────────────────────────┤
│  渲染进程 (renderer/)                        │
│  index.html ─ css/app.css                   │
│  js/  main.js(引导)  ui.js(视图)             │
│       store.js(状态/订阅)  model.js(纯逻辑)  │
└─────────────────────────────────────────────┘
```

**数据流**：`ui.js` 用户操作 → `store.js` 修改内存状态并通知 → 防抖 IPC `save` → 主进程原子写盘。模型层 `model.js` 为**纯函数**（无 DOM/IO），可脱离 Electron 单测。

## 3. 数据模型

### 3.1 Game（游戏，彼此隔离）
```js
{
  id: 'g_xxx',
  name: '我的游戏',
  iconImage: 'data:image/png;base64,...',  // 图片图标（data URL；未设置时显示状态圆点）
  dailyResetHour: 4,        // 每日重置小时（默认凌晨 4 点）
  weeklyResetDay: 1,        // 每周重置日 0=周日 … 6=周六（默认周一）
  archived: false,
  createdAt: 1700000000000,
  sortOrder: 0
}
```

### 3.2 Task（任务）
```js
{
  id: 't_xxx',
  gameId: 'g_xxx',          // ← 隔离键
  title: '每日委托',
  category: 'daily',        // daily | weekly | main | event
  notes: '',
  dueDate: '2025-08-01',    // 活动截止（可选）
  resetMode: 'auto',        // auto=按类型自动; none=手动保持; daily/weekly=手动任务的每日/每周重置
  completions: { 'd:2025-06-01': 1717200000000 },  // 周期键 → 完成时间戳
  archived: false,
  createdAt: 1700000000000,
  sortOrder: 0
}
```

### 3.3 周期键（重置逻辑核心）

| 类别 | 重置方式 | 周期键 | 示例 |
| --- | --- | --- | --- |
| daily | 每天（按游戏重置小时） | `d:YYYY-MM-DD`（重置边界所在日） | 6 月 2 日凌晨 3:59 → `d:2025-06-01`；4:00 → `d:2025-06-02` |
| weekly | 每周（按游戏重置日+小时） | `w:YYYY-MM-DD`（本周起点日） | 周一下午 → `w:2025-06-02` |
| main / event（`resetMode:'none'`） | 手动，保持 | `once` | —— |
| main / event（`resetMode:'daily'|'weekly'`） | 同上 daily/weekly | `d:` / `w:` | —— |

**规则**：任务当前周期"已完成" ⇔ `completions` 中存在当前周期键。

### 3.4 派生状态（model.js 纯函数）
- `periodKeyOf(task, game, now)` → 当前周期键
- `isDone(task, game, now)` / `toggleDone(...)`（写回 completions）
- `overdueInfo(task, now)` → 剩余天数 / 是否过期
- `statsOf(game, tasks, now)` → 每日完成 x/y、每周 x/y、活动临期数
- `historyDots(task, game, now, days=7)` → 最近 7 天完成点阵

## 5. IPC 契约（preload 暴露 `window.api`）

| 通道 | 方向 | 说明 |
| --- | --- | --- |
| `app:info` | → | 平台/版本/Win11/数据目录 |
| `data:load` / `data:save` | ⇄ | 全量读写（保存防抖） |
| `data:export` / `data:import` | → | 另存/选择 JSON 备份 |
| `data:openDir` | → | 打开数据目录 |
| `window:minimize` / `window:togglePin` / `window:close` | → | 窗口控制 |
| `app:autostart:set` / `app:autostart:get` | ⇄ | 开机自启 |

## 6. 关键实现要点

### 6.1 亚克力
```js
const isWin11 = process.platform === 'win32' && os.release().split('.').map(Number)[2] >= 22000;
win = new BrowserWindow({ frame:false, alwaysOnTop:true,
  ...(isWin11 && electronVersionMajor>=23 ? { backgroundMaterial:'acrylic' } : { transparent:true }),
  webPreferences:{ preload, contextIsolation:true, nodeIntegration:false, spellcheck:false } });
```
渲染层背景半透明（`rgba`），亚克力从 OS 透出；Win10 回退由 CSS `backdrop-filter: blur()` 承担。

### 6.2 原子写盘
```js
const tmp = dataFile + '.tmp';
fs.writeFileSync(tmp, json); fs.renameSync(tmp, dataFile); // 同盘 rename 原子
```

### 6.3 悬浮
- 窗口创建即 `alwaysOnTop: true`；标题栏 📌 切换 `win.setAlwaysOnTop(v)`，状态写入设置。
- 关闭按钮默认**隐藏到托盘**（托盘常驻，可退出），符合"常驻悬浮"心智。

## 7. 验证方案

| 层 | 手段 | 命令 |
| --- | --- | --- |
| 模型单测 | Node 直接跑 `model.js`（纯函数），覆盖周期键/到期/统计 | `npm test` |
| 冒烟自检 | Electron `--smoke`：隐藏窗口加载页面 → 页面内自检（存储往返/渲染/模型）→ 输出 JSON 退出码 | `npm run smoke` |
| UI 截图 | Electron `--shots`：注入测试数据（仅临时 userData）→ `capturePage` 存 `docs/screenshots` | `npm run shots` |
