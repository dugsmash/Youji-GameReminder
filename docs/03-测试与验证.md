## 5. 环境限制说明

本次开发/验证环境（虚拟桌面会话）存在两项无法在环境内验证的限制，代码均采用标准实现，在普通 Windows 桌面上生效：

1. **置顶**：该环境连原生 Win32 `SetWindowPos(HWND_TOPMOST)` 都无法维持置顶（检测到全屏覆盖窗口），故 `isAlwaysOnTop()` 在此环境报告 false。实现为标准 Electron 置顶模式（窗口显示后重新应用，规避隐藏窗口时设置被忽略的已知问题）。
2. **亚克力**：该环境桌面背景近乎纯黑，像素级窗内外方差对比无法证明模糊效果。`backgroundMaterial:'acrylic'` 设置成功无报错；Win10 另有 `transparent + backdrop-filter` 回退。

**建议在真实桌面上按 README 快速开始运行，确认置顶与亚克力观感。**
