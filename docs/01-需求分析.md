# 01 · 需求分析

> 产品代号：**游迹（Youji-GameReminder）** —— 面向 PC 的悬浮置顶游戏任务记录器
> 版本：v1.0.0　|　目标平台：Windows 10/11（桌面端）

---

## 1. 背景与痛点

玩家常同时游玩多款游戏，每款游戏又有多种类型的待办：

| 类型 | 例子 | 特征 |
| --- | --- | --- |
| 每日任务（daily） | 每日委托、体力清空 | 每天重置，漏一天就损失一天 |
| 每周任务（weekly） | 周本、深渊 | 每周重置 |
| 主线任务（main） | 剧情、支线、成就 | 一次性，做了就不需要再做 |
| 活动任务（event） | 限时活动、签到、副本 | 有截止日期，过期作废 |

**核心痛点**：
1. **记不清哪些没做**——游戏多、任务多，靠脑子记必然遗漏；
2. **每日/每周任务需要"今天/本周做了没有"**，即按周期自动重置的完成状态；
3. **活动任务有截止时间**，容易错过；
4. **游戏之间信息混杂**——需要严格隔离，互不干扰；
5. 记录器应当**常驻桌面、随时可见**（悬浮置顶），而不是藏在任务栏里等玩家去打开。

## 2. 目标用户与使用场景

- **用户**：同时玩 2 款以上游戏的 PC 玩家。
- **场景**：开机后悬浮窗常驻桌面最上层，扫一眼就知道"今天哪些游戏的每日没做、本周周常还剩什么、哪些活动要过期"；做完一项勾一项；游戏与游戏之间各自独立管理。

## 3. 功能需求

### 3.1 桌面形态（本轮新增重点）
| 编号 | 需求 | 说明 |
| --- | --- | --- |
| F1.1 | **悬浮于桌面最上端** | 窗口默认 `alwaysOnTop`，并提供钉住/取消钉住开关（含全局快捷键） |
| F1.2 | **透明毛玻璃（CSS 高斯模糊）** | 透明窗口 + `backdrop-filter` 模糊桌面；颜色由 CSS 完全控制，点击窗口内外均不变色（弃用系统亚克力：其随焦点切换色调） |
| F1.3 | 无边框窗口 | 自绘标题栏（拖拽区域 + 最小化/置顶/关闭按钮） |
| F1.4 | 系统托盘 | 最小化/关闭时收进托盘，常驻不退出；托盘菜单可显示/退出 |
| F1.5 | 开机自启（可选） | 设置中开关 |
| F1.6 | **鼠标穿透（快捷键切换）** | 全局快捷键（默认 `+`，可在设置中录制修改）切换鼠标穿透，游戏内操作不被悬浮窗遮挡；再次按下恢复；穿透时界面显示标识 |
| F1.7 | 窗口透明度可调 | 设置中 20%–100% 以 1% 步进微调 |

### 3.2 游戏管理（隔离）
| 编号 | 需求 |
| --- | --- |
| F2.1 | 添加/编辑/删除/归档游戏（名称、本地图片图标；未设置时显示状态圆点） |
| F2.2 | 每款游戏独立配置**每日重置小时**（如凌晨 4 点）与**每周重置日**（如周一） |
| F2.3 | 游戏数据完全隔离：任务、完成记录都挂在游戏 ID 下 |

### 3.3 任务管理
| 编号 | 需求 |
| --- | --- |
| F3.1 | 四类任务：每日 / 每周 / 主线 / 活动 |
| F3.2 | 任务字段：标题、备注、截止日期（活动）、重置方式（主线/活动可选"不自动重置/每日/每周"） |
| F3.3 | 完成勾选：按周期自动重置（每日按重置小时、每周按重置日）；主线/活动默认保持勾选，可手动取消 |
| F3.4 | 完成历史：每日任务显示最近 7 天完成点阵 |
| F3.5 | 编辑/删除/归档任务 |

### 3.4 总览（今日待办）
| 编号 | 需求 |
| --- | --- |
| F4.1 | 一屏列出**所有游戏**今天未完成的每日、本周未完成的每周、已过期/临期活动、未完成主线 |
| F4.2 | 当日总体完成度（每日任务 x/y） |

### 3.5 数据
| 编号 | 需求 |
| --- | --- |
| F5.1 | 本地 JSON 持久化（`userData/data.json`），自动保存 |
| F5.2 | 导出/导入备份文件；一键打开数据目录 |

## 4. 非功能需求

- **离线可用**：纯本地，无网络依赖；
- **轻量**：常驻内存占用小，启动快；
- **可靠性**：保存采用"临时文件 + 原子替换"，防止写坏数据；
- **可验证**：提供领域模型单元测试、Electron 冒烟自检、截图验证三种验证手段。

## 5. 范围边界（v1 不含）

- 不接入游戏官方 API / 自动化识别（后续可扩展）；
- 不做云端同步（后续可扩展）；
- 不做多用户/密码。

## 6. 验收标准

1. 双击 `npm start` 后窗口悬浮于桌面最上层，带毛玻璃模糊质感；
2. 可添加 ≥2 款游戏，各自任务互不可见；
3. 每日任务在配置的重置小时自动变为"未完成"；每周同理；
4. 活动任务显示截止倒计时，过期红色高亮；
5. 总览页能列出跨游戏未完成项；
6. 数据可导出/导入，重开应用不丢失。
