## 简介

游迹是一款**轻量**、**完全离线**的桌面游戏任务记录器，专治"同时玩好几个游戏、记不清还有哪些没做"。添加游戏、填好任务（每日 / 每周 / 主线 / 限时活动），应用就以一个常驻桌面的毛玻璃小窗悬浮在最上层。各游戏严格隔离，每日 / 每周任务按你配置的重置时刻自动恢复未完成；**今日待办**会按"活动最先到期"的游戏排在最前，一眼就知道还有什么没做。

所有数据保存在本地 JSON 文件里：无账号、无云端、无遥测。

## 功能

### Windows 桌面应用 · v1.0.0

| 功能 | 说明 |
|---|---|
| **悬浮置顶** | 始终显示在桌面最上层（含全屏游戏，周期性重新置顶兜底）；📌 按钮 / `Ctrl+Shift+P` 切换；关闭收进系统托盘常驻 |
| **毛玻璃外观，颜色稳定** | 透明窗口 + CSS `backdrop-filter` 模糊；颜色完全由 CSS 控制，点击窗口内外均不变色（为此弃用了系统亚克力） |
| **多游戏隔离** | 各游戏数据互不干扰；侧边栏可拖拽排序、可收起、可调宽 |
| **四类任务，自动重置** | 每日 / 每周 / 主线 / 活动；每日与每周按各游戏的重置时刻自动恢复未完成；主线 / 活动保持勾选直到手动取消 |
| **今日待办按紧急度排序** | 跨游戏比较：**活动剩余日期最短的游戏排最前**；游戏内顺序为 每日 → 每周 → 活动 → 主线，活动按剩余天数升序 |
| **截止日期两种填法** | 活动任务可直接选日期，或直接填"剩几天"（如填 3 = 三天后截止） |
| **仅图片图标** | 不使用 emoji 图标；上传本地图片作为游戏图标；未设置图标时显示状态圆点（红黄蓝绿灰 = 完成情况） |
| **鼠标穿透** | 开启后悬浮窗不响应鼠标点击，游戏操作不受遮挡；全局快捷键 `Ctrl+Shift++`（可在设置中修改）、标题栏按钮或托盘菜单切换 |
| **窗口透明度** | 20%–100% 以 1% 步进微调，游戏内更少遮挡 |
| **近 7 天完成点阵** | 每日任务显示最近 7 天是否完成 |
| **背景图与模糊度** | 每个游戏可单独设置背景图与模糊度，也可使用全局背景 |
| **本地 JSON 存储** | 原子写盘；随时导出 / 导入完整备份 |
| **自绘缩放手柄** | 无边框窗口，拖拽任意边缘 / 角落即可调整大小 |
| **全局快捷键** | `Ctrl+Shift+P` 置顶 · `Ctrl+Shift+H` 显示/隐藏 · `Ctrl+Shift++` 鼠标穿透 |

## 快速开始

### 安装（普通用户）

1. 从 **Releases** 页面下载最新安装程序。
2. 运行安装程序按向导安装（可自定义安装目录，自动创建桌面快捷方式）。
3. 首次打开是空页面，点侧边栏「＋ 添加游戏」开始；点关闭按钮只是收进托盘——用「托盘 → 退出」才能真正退出。

### 从源码构建（开发者）

**环境要求**

| 工具 | 版本 |
|---|---|
| 系统 | Windows 10 / 11 |
| Node.js | 18 及以上 |
| npm | 随 Node.js 自带 |

**安装依赖**

```bash
npm install
```

> 国内用户可使用镜像加速 Electron 二进制下载：

```bash
$env:ELECTRON_MIRROR="https://npmmirror.com/mirrors/electron/"
npm install
```

**开发运行**

```bash
npm start
```

**验证**

```bash
npm test          # 领域模型单元测试
npm run smoke     # Electron 冒烟自检（自动退出并给出通过/失败结果）
```

**打包**

```bash
npm run pack       # → dist/游迹-1.0.0.exe（NSIS 安装程序）
npm run pack:dir   # → dist/win-unpacked/（免安装目录，供调试）
```

## 使用指南

### 首次配置

1. 点「＋ 添加游戏」，填游戏名并**上传本地图片**作为图标（背景图可选）。
2. 配置该游戏的**每日重置时间**与**每周重置日**。
3. 进入游戏后点「＋ 添加任务」，选择类型：每日 / 每周 / 主线 / 活动。
4. 活动任务设置截止时间有两种方式——**选日期**，或直接填**剩余天数**。

### 日常使用

- 「今日待办」列出所有游戏未完成的任务；**活动剩余日期最短的游戏排最前**；游戏内顺序为 每日 → 每周 → 活动 → 主线，活动按剩余天数升序。
- 点圆圈勾选完成。每日 / 每周任务会在下一个重置时刻自动变回未完成；主线 / 活动保持完成直到手动取消。
- 侧边栏圆点显示各游戏完成状态：红=全部未完成，黄=有每日未完成，蓝=仅每周未完成，绿=全部完成，灰=无每日/每周任务。

### 游戏场景

- 按 **`Ctrl+Shift++`**（或标题栏 🖱 按钮）开启鼠标穿透——鼠标穿过悬浮窗直达游戏，窗口保持可见；再按一次恢复。快捷键可在 设置 → 穿透快捷键 中修改。
- 开启**鼠标穿透** + 调整「窗口透明度」是游戏中使用的标准姿势。
- 全屏游戏下窗口会保持在最上层；万一被覆盖，重新切换置顶或使用托盘即可。

### 快捷键

| 快捷键 | 功能 |
|---|---|
| `Ctrl+Shift+P` | 切换窗口置顶 |
| `Ctrl+Shift+H` | 显示 / 隐藏主窗口 |
| `Ctrl+Shift++` | 切换鼠标穿透 |
| `Esc` | 关闭当前弹窗 |

### 数据与备份

所有数据存放在一个 JSON 文件里——设置 → 本地存储 → 打开目录即可查看。使用「导出 / 导入」备份或迁移数据。**无云同步**；卸载或删除文件将清空一切，重装前请先导出备份。

## 隐私与安全

- **完全离线**——应用不发起任何网络请求，无账号、无云端、无广告、无统计、无追踪 SDK。
- **数据只留在本机**——本地 JSON 文件（设置 → 本地存储 → 打开目录 可查看路径）。
- **备份归你所有**——导出的纯 JSON 可随时查看、归档、恢复。
- **无需特殊权限**——开机自启为可选且默认关闭。
